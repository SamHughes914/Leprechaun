# Leprechaun
ENGI 5006 Leprechaun group project S1 2026

ENGI 5006 Engineering data analyitics group project. 
Code is in .qmd format and readable using R studio. 
The .csv files must be in the working directory for the .qmd and .rmd files to function. 
The file group_project_{city_name}_{station_name}.qmd analyses the data for the respective city. 
The file Data_review.rmd generates box plots and summary statistics tables for the 8 cities of interest.
